# Creator OS — Instruções para Claude Code

## Objetivo

Este projeto é uma operação de criação de conteúdo digital
para Instagram, TikTok e Facebook.

O projeto possui três verticais editoriais:

1. Mistério + investigação + psicologia
2. Astronomia + ciência + ficção científica
3. Negócios + dinheiro + comportamento

---

# Princípios

## Originalidade

Não copiar conteúdo de terceiros.

Não produzir conteúdo genérico ou repetitivo.

IA deve ser utilizada como ferramenta de produção,
pesquisa, organização, análise e criatividade.

---

# Pesquisa

Sempre separar:

- fatos confirmados
- interpretação
- hipótese
- especulação

Quando uma informação factual for importante,
priorizar fontes primárias ou fontes confiáveis.

Não inventar estatísticas, citações, eventos ou fontes.

---

# Roteiros

Todo roteiro deve possuir:

1. Hook
2. Contexto
3. Desenvolvimento
4. Revelação ou insight
5. Conclusão
6. CTA

Priorizar:

- clareza
- narrativa
- curiosidade
- retenção
- linguagem brasileira natural.

Evitar:

- clickbait enganoso
- exageros
- afirmações sem evidência
- frases genéricas de IA.

---

# Conteúdo de psicologia

Não diagnosticar pessoas.

Não apresentar especulações psicológicas como diagnóstico.

Distinguir conhecimento científico de opinião.

---

# Conteúdo financeiro

Não oferecer aconselhamento financeiro personalizado.

Não prometer enriquecimento.

Distinguir educação financeira de recomendação de investimento.

---

# Conteúdo científico

Distinguir:

- fato científico
- hipótese científica
- especulação
- visualização artística.

Não apresentar imagens geradas por IA como fotografias reais.

---

# Métricas

Sempre que houver dados de desempenho,
analisar:

- visualizações
- retenção
- compartilhamentos
- comentários
- seguidores ganhos
- taxa de engajamento
- duração
- hook
- tema
- formato.

O objetivo é descobrir padrões,
não apenas identificar vídeos com muitas visualizações.

---

# Workflow

Antes de criar conteúdo:

1. entender o objetivo
2. identificar a vertical
3. pesquisar
4. validar fatos
5. criar ideias
6. selecionar a melhor ideia
7. escrever roteiro
8. criar storyboard
9. criar prompts visuais
10. preparar publicação
11. registrar no banco de dados
12. analisar resultados posteriormente.

---

# Segurança

Nunca apagar arquivos ou executar comandos destrutivos
sem confirmação explícita.

Nunca expor credenciais, tokens ou API keys.

Nunca adicionar secrets ao Git.

Antes de operações Git potencialmente destrutivas,
explicar o que será feito.
